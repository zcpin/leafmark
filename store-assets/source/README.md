# 素材制作说明

## 来源

- Logo 使用项目的 `scripts/generate-icons.mjs` 绘制，商店 128px 图标采用 96px 图案加透明留白。
- 截图来自 `dist/` 中的生产构建，尺寸为 1280×800，使用 `demo-data.mjs` 内的公开示例网址。
- 为突出预览和清理界面的内容，后面三张截图使用应用自身的 0% 面板透明度设置。
- 捕获过程仅替换运行页面中的演示书签状态及界面语言，不修改页面布局、文案或功能代码。重复分组、文件夹预览和设置面板由实际组件渲染。
- 推广图以 `promo.html` 为可编辑源文件，只有 Leafmark 品牌名称，不包含未经验证的功能或排名声明。
- 没有使用个人书签、私人网址、账号截图或第三方宣传图片。

## 生成步骤

1. `pnpm icons`，然后 `pnpm build` 和 `pnpm zip`。
2. 运行 `node scripts/store-assets/prepare.mjs` 生成图标、隐私政策 HTML 和安装包副本。
3. 在独立浏览器测试配置文件中启动 CDP，不复用个人配置文件，不终止用户现有浏览器。
4. 运行 `node scripts/store-assets/capture.mjs --port 9346`。脚本在本机启动临时素材服务器，创建并关闭自己的页面，输出中英截图与两张推广图。
5. 运行 `node scripts/store-assets/validate.mjs`，检查图片尺寸、PNG 类型、文案长度和包内文件，并生成清单及 SHA-256 校验值。

截图是无额外边框、无文字包装的完整页面；两张推广图是语言通用品牌图。提交时不要把 `source/` 文件当成图片上传。
