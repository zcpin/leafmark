### 需求细化：A9 目录悬停弹窗（2026-08-27 变更；同日修订样式）

**交互取代**：参考项目是「点击文件夹 → 进入该目录展示链接」；Leafmark 改为**悬停即预览**，不再有页面内层级跳转。

**行为规格：**

| 项 | 规格 |
|----|------|
| 触发 | 鼠标悬停文件夹卡片约 **250ms** 后弹窗出现（防误触） |
| 保持 | 鼠标移入弹窗范围内 → 弹窗持续显示（不因离开原文件夹而关闭） |
| 收起 | 鼠标离开「文件夹卡片 + 弹窗」整体区域后 **~200ms** 宽限期（允许斜向移动），仍未返回则收起 |
| 强制关闭 | `Esc`、页面滚动、点击弹窗内书签打开后（整链关闭） |
| 空文件夹 | 显示空态文案 |
| 定位 | 主页面卡片在**下方**展开；级联层在**右侧**展开；视口边缘自动翻转/内收，不溢出屏幕 |
| 渲染 | 悬停时才渲染弹窗内容（懒渲染，书签树数据已在内存中，无需额外 IO） |
| 触屏兜底 | 平板/触屏无 hover：单击文件夹 = 立即弹出，点击外部关闭 |

**样式规格（2026-08-27 修订）**：
- 弹窗为**卡片网格面板**：与主页面页签卡片**完全同款**（favicon/文件夹图标 + 标题 + 数量徽标 + 毛玻璃卡片），书签可点击打开（遵循 G5），同样支持右键菜单
- **一行多个页签、自动换行，不出现滚动条**（面板宽 `min(520px, 100vw-48px)`，列宽 `auto-fill minmax(150px,1fr)`）
- **2026-09-09 大目录补充**：按视口高度和卡片高度计算每页容量，超量内容通过上一页/下一页访问；只挂载当前页卡片，保留无滚动条交互。调整窗口或卡片高度时重新计算容量，并校正当前页。
- 子文件夹卡片在面板内**悬停级联展开下一层面板**（同款网格样式，右侧展开）

**连带调整：**
- A6 面包屑不再承担「进入/返回」职责，仅显示主视图当前文件夹路径（可点击跳转）
- 主视图切换途径：面包屑跳转、右键「设为主页」（A2）
- 点击文件夹卡片本身无动作（进入行为已移除）
- 拖拽排序（A4）进行中需抑制悬停弹窗触发

### 需求细化：F8 毛玻璃主题（2026-08-27 变更）

**定义**：半透明底色 + `backdrop-filter: blur()` 的磨砂玻璃质感，应用于书签卡片、悬停弹窗、侧边栏、右键菜单、设置面板、引导浮层等所有浮起表面。

**规格：**
- 统一设计令牌：如浅色 `rgba(255,255,255,0.6)` + `backdrop-blur(24px)` + 1px 半透明白描边 + 柔和投影；深色模式用深色半透底。以 Tailwind 工具类封装成 `.glass` / `.glass-strong` 复用
- 与 F1 暗黑模式、F2/F3/F5 背景（壁纸/纯色/渐变）组合时均需正常呈现：壁纸之上效果最佳，纯色之上自动弱化为柔和半透明（可接受）
- 毛玻璃层数过多有渲染开销：书签卡片数量大（数百级）时以「卡片轻模糊 + 弹窗/侧栏重模糊」分层控制；低性能设备提供关闭模糊的降级选项（仅半透明底）备选
- Chrome/Edge（Chromium）对 `backdrop-filter` 支持完整，无兼容性风险

## 二、Manifest 权限（最终清单）

```json
"permissions": ["bookmarks", "favicon", "storage", "tabGroups"],
"optional_host_permissions": ["http://*/*", "https://*/*"]
```

- `bookmarks` — 读取/排序/编辑书签（核心）
- `favicon` — 展示书签图标
- `storage` — 持久化设置、上传壁纸、最近一次删除快照及检测范围/忽略名单
- `tabGroups` — B3 批量打开后的标签组命名与颜色设置。2026-09-09 提审核对：`tabs.create` / `tabs.group` 不需要敏感 `tabs` 权限，项目不读取标签页的 URL/标题，已移除该权限。

最低支持 Chrome/Edge 111；manifest 和 Vite 构建目标与 Tailwind CSS 4 的兼容范围对齐。

**硬性边界：**
- 固定 `host_permissions` 为空；链接检测使用 `optional_host_permissions`，仅在用户点击开始检测时申请授权并访问收藏网址
- ❌ 无 `content_scripts`（不向任何网页注入代码）
- ❌ 无 `history` / `management` / `sidePanel` / `commands` 权限
- ✅ 无遥测、无账号，不向开发者服务器上传书签清单或检测结果；请求由浏览器直接发往收藏网站，结果仅保留在当前页面内存中
- ✅ favicon 仍使用浏览器扩展 API；链接检测不加载或执行远程页面代码，不携带 Cookie/Referer

## 三、技术栈（已确认）

| 层 | 选型 | 版本策略 |
|----|------|----------|
| 框架 | **Vue 3**（Composition API + `<script setup>`） | 脚手架时取最新稳定版 |
| 构建 | **Vite** | 同上（不硬编码版本号） |
| 语言 | **TypeScript** | 同上 |
| 样式 | **Tailwind CSS** | 同上（当前主版本为 v4 体系，含 `@tailwindcss/vite` 插件方式） |
| 状态管理 | **Pinia** | 同上 |
| 二维码 | `qrcode`（B2） | npm 最新 |
| 拖拽 | SortableJS 或原生 HTML5 DnD | Phase 2 实现时对比后定 |
| 类型 | `@types/chrome` | 最新 |
| 国际化 | `chrome.i18n` + `_locales/` | 扩展原生方案 |
| 测试 | Vitest + `@vue/test-utils`；E2E 视需要 Playwright | TDD，核心逻辑覆盖率 80%+ |
| 包管理 | pnpm（若环境可用）或 npm | 脚手架时定 |

**商店合规注意（写入技术约束）：**
- 不加载任何远程代码/字体/图标（CDN 字体、运行时远程脚本一律禁用——商店对远程代码零容忍）；图标用本地 SVG。
- Tailwind v4 默认无远程依赖，满足 CSP。
- MV3 `background.service_worker` 尽量精简（本项目后台逻辑极少，预期近乎空壳）。
