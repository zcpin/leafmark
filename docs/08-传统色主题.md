# 传统色主题

> 2026-09-10：按用户要求使用 doudou-color 技能，为 1.1.0 新增六款内置主题，均提供浅色与深色版本。

## 主题与意境

| 主题 | 意境 | 浅色渐变（起点 → 中点 → 终点） | 深色渐变（起点 → 中点 → 终点） |

## 界面应用与可读性

以 60–30–10 的视觉比重组织页面：低饱和背景承担大面积底衬，书签浮岛与卡片形成主体，勾选和主要操作按钮使用小面积强调色。比例是布局指导，不对应渐变节点的百分比。

背景使用 135° 渐变，三个节点位于 0%、50%、100%。设置面板的缩略图与实际页面共用同一组色值，并随深浅模式变化；主题显示中英文名称和选中标记。主题选择仍保存到浏览器同步设置中。

新增主题背景上的辅助文字使用 `text-slate-600` / `dark:text-slate-300`。从生产构建的浏览器计算样式读取文字颜色，并转换为 sRGB：浅色为 `#45556c`，深色为 `#cad5e2`。对每段渐变按 sRGB 插值采样 101 个位置，以下为最小 WCAG 对比度；普通文本 AA 目标为 4.5:1。此结果针对这些前景与背景组合，不代表任意自定义壁纸和透明度组合的整体无障碍认证。

| 主题 | 浅色最小对比度 | 深色最小对比度 |
| --- | --- | --- |
| 雨过天青 | 5.55:1 | 8.58:1 |
| 艾绿春山 | 4.92:1 | 7.80:1 |
| 藕荷暮色 | 4.70:1 | 9.22:1 |
| 酪黄暖阳 | 5.77:1 | 8.33:1 |
| 丁香微雨 | 5.51:1 | 10.55:1 |
| 月白松烟 | 6.90:1 | 8.33:1 |

## 工程令牌

`src/lib/backgrounds.ts` 是主题名称和深浅色值的单一来源，`themeGradient()` 同时供 `App.vue` 和 `SettingsPanel.vue` 使用。旧主题 id 保持兼容；无法识别的 id 回退到默认翡翠主题。

以雨过天青为例，其色值可表达为：

```css
:root {
  --celadon-light-start: #eef7f2; /* 月白 */
  --celadon-light-middle: #d0dfe6; /* 远天蓝 */
  --celadon-light-end: #f7f4ed; /* 鱼肚白 */
  --celadon-dark-start: #142334; /* 钢青 */
  --celadon-dark-middle: #131824; /* 燕颔蓝 */
  --celadon-dark-end: #2b333e; /* 青灰 */
}
```

实际组件通过 TypeScript 主题表生成 `background-image`，不需要引入外部字体、图片、运行时依赖或网站权限。
