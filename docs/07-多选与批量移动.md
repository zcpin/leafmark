# 多选与批量移动

> 2026-09-10：用户确认本轮优先开发多选与批量移动，大目录性能后排。对应更新候选版 1.1.0。
> 状态：实现、自动化验证及独立 Edge 生产构建验证已完成。

## 用户操作

顶栏「多选」进入当前目录的选择模式，也可右键任意书签或文件夹选择「多选」。从悬停面板发起时，会在主网格展示该项目所在目录并选中该项目，不改变保存的主页设置。

- 点击卡片切换选择，Shift 点击追加连续范围；键盘 Space/Enter 可勾选。
- 工具栏显示所选数量，提供全选、取消全选、移动到、完成；Ctrl/⌘+A 全选，Esc 退出。
- 选择模式下点击只负责勾选，暂停单项拖拽和文件夹悬停，避免误打开或误移动。普通模式继续支持原有打开快捷键。
- 选择目标目录后，按主网格展示顺序追加到目标末尾。文件夹连同其子树移动，书签 id 不变。
- 切换目录结束选择。取消移动窗口保留当前选择；全部成功后退出选择并将焦点还给顶栏入口。

## 边界与失败处理

目标选择器显示完整目录路径，禁选原目录、所选文件夹自身及其子目录、浏览器虚拟根和管理员管理目录。系统根文件夹不可作为移动源。

实际写回在 `leafmark-bookmark-write` Web Lock 内重新读取整棵树，和已有删除、恢复操作共用互斥。不存在、已改变父目录或不可移动的项目会跳过；两个页面同时提交相同项目时，后一个会核对新父目录，避免重复移动。

Chrome API 按项执行移动，无法提供整个批次的事务回滚。单项失败不阻塞后续项目，窗口说明成功数量并保留失败项；重试只提交剩余选择，继续追加到末尾。移动期间禁止重复提交和关闭窗口。读取失败时不执行移动，保留可重试错误。

移动不创建删除快照，也不提供移动撤销。所有操作沿用 `bookmarks` 权限，不增加权限或网络访问。
