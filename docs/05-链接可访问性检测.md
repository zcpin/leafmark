# 收藏链接可访问性检测

> 2026-09-07 · 用户要求：检查收藏链接，列出不可访问项，超时可配置，方便用户删除。
> 实现完成：2026-09-08。

入口位于设置 → 通用，用户点击「开始检测」后申请 HTTP/HTTPS 可选网站访问权限。默认超时 10 秒，可调整为 3–60 秒并保存。默认检测全部收藏链接，也可选择指定文件夹（含子目录），并忽略指定域名及其子域名；范围和忽略名单保存在本机。最多并发 4 个网址，相同网址忽略片段后复用一次请求。

请求优先使用 HEAD；服务器返回 405/501 时回退到带 Range 的 GET，响应头到达后取消正文读取。两次请求共用同一个超时预算，超时记为不可访问。请求不携带 Cookie 或 Referer；仅允许 HTTP/HTTPS 且无内嵌用户名/密码的 URL。

结果分为可访问、HTTP 错误、超时、网络失败、访问受限、跳过。401/403/407/429 单列为需要确认。状态只反映本次 HTTP 请求，不解析网页正文；返回 200 的错误提示页或登录后的内容无法据此判断。用户可以打开核实、重试，并勾选需要删除的链接。

删除需要二次确认，只删除所选书签，不递归删除文件夹。删除前刷新书签树并核对 URL 与检测时相同；已更改/已删除的书签跳过，单项删除失败保留结果。清理通过共用的删除 store 保存最近一次本地快照，可在面板或顶栏撤销。检测结果仅在当前页面内存中保存，关闭面板或页面会停止请求；已完成的结果在本页重新打开面板时保留。修改检测范围或忽略名单会停止旧任务并清除旧结果；范围目录失效时禁止开始，避免意外扩大到全部书签。

实现拆分：`lib/link-checker.ts` 负责超时和并发，`lib/link-check-permissions.ts` 负责用户手势内申请权限，`stores/link-checker.ts` 管理任务与删除，`LinkCheckDialog.vue` 展示配置、进度和结果。

验证重点：超时实际中止、HEAD/GET 共用预算、取消不产生失效记录、并发上限和网址去重、权限拒绝后零请求、旧书签结果不能误删新链接、保存配置和部分删除失败。

参考：[Chrome 跨域网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[Chrome 可选权限与用户手势](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

## 验证记录

- 全量 201 个测试（31 个文件）、类型检查、lint 和构建通过
- 使用真实本地 HTTP 服务验证 200、重定向、404、403、HEAD 不支持后的 GET 回退、超时中止，并核对请求未携带 Cookie/Referer
- 在独立 Edge 环境加载实际构建的扩展，验证设置入口和原生可选权限申请；结果列表和删除确认界面使用内存样例验证
- 自动化环境未批准原生权限弹窗，因此「用户授权后扫描真实网站」的完整流程仍需在普通浏览器窗口验证；真实书签没有用于自动化删除测试
