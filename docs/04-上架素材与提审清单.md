# Leafmark 上架素材与提审清单

> 2026-09-09 更新 · 对应扩展 v1.0.0

完整素材已迁移到独立的 [store-assets/](../store-assets/README.md)。本文件作为项目文档入口，商店字段和隐私政策以后以素材目录为准。

## 当前提审候选版

- MV3，新标签页覆盖，无 content scripts 或后台 service worker。
- 最低 Chrome/Edge 111，与 Vite 构建目标和 Tailwind CSS 4 的支持范围一致。
- 显式固定权限为 `bookmarks`、`favicon`、`storage`、`tabGroups`。
- HTTP/HTTPS 网站权限为可选，只在手动开始链接检测时申请。
- 原生 Edge 测试确认：不声明 `tabs` 权限也可以创建标签页、分组及设置组名/颜色。
- 本地自动化、覆盖率、类型、lint、构建及素材校验结果见 [实现计划](./03-实现计划.md#最新质量门2026-09-09)。

## 正式提交前

1. 完成 Chrome Web Store / Microsoft Partner Center 开发者账号与发布者信息。
2. 公开发布隐私政策，并核对 URL 无需登录即可访问。
3. 按实际数据处理填写后台披露：本地书签处理、浏览器设置同步、用户触发的目标网站请求。
4. 在测试配置文件中核对新标签页提示、首次可选网站权限授权后的真实链接检测。
5. 上传安装包、对应语言的文案及图片，填写审核备注后提交。

没有开发者服务器不等于不处理用户数据。Chrome 官方明确要求本地处理用户信息的扩展也提供隐私政策。当前代码与素材是提审候选版，本次未向商店提交，也不代表已经通过审核。
