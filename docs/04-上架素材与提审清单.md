## 一、商店 Listing 文案

### 英文（主语言）

**名称**：Leafmark — Bookmark New Tab

**简短描述**（132 字符内）：
> Turn your new tab into a clean glass shelf for bookmarks. Preview folders, manage links, and check for unreachable bookmarks.

**详细描述**：

```
Leafmark turns your browser bookmarks into a beautiful new tab page — a clean, frosted-glass shelf where everything you saved is finally visible again.

✨ WHAT IT DOES
• Your bookmarks, on every new tab — pick any folder as your homepage
• Hover any folder to preview its bookmarks in a floating glass panel (cascades into subfolders, no clicking needed)
• Fully manage bookmarks: edit, delete, copy URL, drag to reorder — changes write straight back to your real bookmark tree
• Undo the most recent deletion, including folders and selected cleanup batches
• Find duplicate bookmarks by exact URL and choose which copies to keep
• Drag with before/after insertion hints; Ctrl/Command-click or middle-click to open links in the background
• Open a whole folder at once into a tidy, color-coded tab group
• Generate a QR code for any bookmark to send it to your phone
• Check all bookmarks or a selected folder with a configurable timeout and ignored domains, review failures, and confirm selected deletions

🎨 MAKE IT YOURS
• Light / dark / auto theme with frosted-glass cards
• 3 preset wallpapers + upload your own (auto-compressed)
• 4 gradient backgrounds
• Adjustable card size and page width
• Time-based greeting
• Optional clock, year-progress, and bookmark-statistics displays
• Adjustable panel transparency for readable text over wallpapers
• English & 中文 UI

🔒 PRIVATE BY DESIGN
• Runs in your browser — no developer accounts, analytics, or tracking
• Bookmark lists and check results are not uploaded to the developer or a checking service
• Link checks contact bookmarked sites directly only when you start a check and grant website access
• Zero remote code

📋 PERMISSIONS (and why)
• bookmarks — read & manage your bookmarks (the entire point of the extension)
• favicon — display website icons next to bookmarks
• storage — save settings, wallpapers, the latest deletion snapshot, and link-check options
• tabs / tabGroups — "Open all" places folder bookmarks into one labeled tab group
• Optional website access — check HTTP/HTTPS bookmark availability, including redirects, when you request it

New to Leafmark? A 3-step guide shows you the ropes on first launch.
```

## 二、隐私声明（Privacy Policy）

> 提审表单按实际数据处理行为填写。以下文案包含用户主动触发的网址请求和浏览器设置同步：

```
Leafmark does not collect analytics or upload bookmark lists or check results to the developer's servers.
Processing happens in your browser:
- Bookmark data is read/written only via the browser's own bookmarks API
- Appearance preferences, display switches, and the link-check timeout use browser extension sync storage. The browser may synchronize these preferences using its own sync service.
- Wallpapers, the latest deletion snapshot (including bookmark titles, URLs, and folder structure), and the selected check folder/ignored domains use extension local storage on this device. The deletion snapshot is replaced by the next successful deletion and cleared after a successful undo.
- When you start a link check and grant optional website access, the browser sends HTTP/HTTPS requests directly to bookmarked sites. Those sites can receive the requested URL and normal network metadata such as your IP address.
- Link checks omit cookies and referrer information. Results remain in the current page's memory and are not uploaded to a checking service.
- The extension contains no analytics, ads, tracking, or remotely executed code.
```

**权限用途字段（提审表单逐项填写）**：

| 权限 | 用途说明（中英对照） |
|------|----------------------|
| bookmarks | 读取并管理书签：展示、排序、编辑、删除 / Read & manage bookmarks: display, reorder, edit, delete |
| favicon | 在书签卡片旁显示网站图标 / Display website icons next to bookmarks |
| storage | 保存用户设置、壁纸、最近一次删除快照及检测配置 / Save settings, wallpapers, the latest deletion snapshot, and link-check options |
| tabs | 「全部打开」时创建标签页 / Create tabs for "Open all" |
| tabGroups | 将批量打开的书签收进一个标签组 / Group opened bookmarks into one tab group |
| 可选 HTTP/HTTPS 网站访问 | 用户手动触发时检测收藏网址及跳转目标，不加载或执行远程代码 / Check bookmarked URLs and redirects on user request without executing remote code |

## 四、提审步骤

### Chrome Web Store（$5 一次性注册费）

1. https://chrome.google.com/webstore/devconsole 登录 Google 账号，完成开发者注册（付 $5）
2. 「新增商品」→ 上传 `leafmark-v1.0.0.zip`（`pnpm build && pnpm zip` 生成）
3. 填写商店信息：
   - 名称/描述：用上方文案
   - 语言：English（主）+ 中文（简体）
   - 类别：生产力工具 / Productivity
   - 图标：`public/icons/icon-128.png`
   - 截图：至少 1 张（建议 5 张全传）+ 1280×800 商店横图（可用主页面截图代替）
4. 隐私：勾选「不收集用户数据」；权限用途逐项填写（用上方表格文案）
5. 分布：所有地区；可见性：公开
6. 提交审核（新扩展通常 1~7 天）

### Microsoft Edge Add-ons（免费）

1. https://partner.microsoft.com/dashboard/microsoftedge 注册开发者账号（个人即可）
2. 「Create new extension」→ 上传同一个 `leafmark-v1.0.0.zip`
3. 填写同款名称/描述/截图/隐私声明（Edge 表单与 Chrome 类似，可复用全部文案）
4. 提交审核（通常 1~5 天）

> 注意：两家商店用同一 zip；版本号共享 manifest 中的 `version` 字段，后续发版需同步递增。

## 六、已知限制（如实披露）

- 拖拽排序落点：卡片两侧 = 同级其前/后；文件夹卡片中部 = 移入；空白区 = 移到末尾；拖拽期间显示落点提示
- 撤销保留最近一次删除；恢复书签使用浏览器分配的新 id，无法保留历史创建时间

- 触屏设备上文件夹单击即弹窗（hover 语义的兜底）
