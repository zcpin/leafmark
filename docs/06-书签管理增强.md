# 书签管理增强

> 2026-09-08：用户确认以下五项全部实施，按优先级推进。
> 状态：五项实现及自动化验证均已完成。

1. 删除撤销：右键删除、批量清理共用最近一次删除记录；保存原目录和顺序，支持本地恢复，原目录失效时回退书签栏。
2. 重复书签检测：按完整 URL 精确分组，展示目录位置，由用户选择保留项，删除接入撤销。
3. 检测范围与忽略名单：全部书签或指定文件夹（含子目录）；忽略指定域名及其子域名，设置持久化。
4. 拖拽与快捷打开：插入前/后提示、文件夹中部移入提示；Ctrl/⌘ 点击和中键后台打开。
5. 页面显示开关：时钟、年度进度、统计信息分别开关，持久化并即时生效。

## 数据与边界

- 最近一次删除快照和检测范围/忽略名单存于 `storage.local`；显示开关和检测超时存于 `storage.sync`。撤销记录会在下一次成功删除时替换，成功恢复后清空。
- 浏览器恢复书签会分配新 id；代码同步修正恢复子树中原主页与检测目录的引用。原生书签的历史创建时间无法通过恢复接口保留。
- 链接检测结果仍只保留在当前页面内存中。网站访问权限与真实网站检测的验证边界沿用 [05-链接可访问性检测.md](./05-链接可访问性检测.md)。
- 商店账号提审、原生权限弹窗授权后的完整真实网站扫描，以及用户自己的书签验收仍由用户在普通扩展窗口完成。
