## Phase 0 — 脚手架（半天）

**任务**
1. Vite + Vue 3 + TS 脚手架（`npm create vite@latest`，vue-ts 模板）
2. 接入 Tailwind（v4 `@tailwindcss/vite`）、路径别名 `@/`
3. `public/manifest.json` 静态 MV3 manifest：仅 `chrome_url_overrides.newtab` + 五项固定权限；链接检测声明 HTTP/HTTPS 可选网站权限，无 content_scripts
4. 扩展构建方案：手动多入口构建，构建时复制 `public/manifest.json`（Plan B）
5. `@types/chrome`、ESLint、Prettier
6. 临时占位图标（正式 logo 后补）

**验收**
- `加载已解压的扩展程序` 后打开新标签页，显示 Vue 渲染的空白页
- 控制台无错误；manifest 权限仅五项

**完成记录（2026-08-27）** ✅
- 版本：Vue 3.5.41 / Pinia 4.0.3 / Vite 8.2.2（rolldown）/ TypeScript 5.9.3 / Tailwind 4.3.3 / ESLint 10 / vue-tsc 3.3.11

**布局重构（2026-08-31，用户反馈「下半部分空白难看」后迭代）**

问题根因：主区是整屏毛玻璃容器（`h-screen` + `overflow-hidden`），书签网格只占上半部分，下半全是空的半透明玻璃，观感空洞。

- **多选与移动**：顶栏和右键入口、Shift 连选、Ctrl/⌘+A 全选、完整文件夹移动、目标路径选择与循环目录保护。跨页面写锁内重新读取书签，跳过旧选择，顺序追加；部分失败保留剩余项重试。详见 [07-多选与批量移动.md](./07-多选与批量移动.md)。
- **交互收尾**：右键菜单纳入悬停面板的同一关闭边界，真实 pointerdown 不再提前收起预览；退出多选或全部移出后恢复入口焦点。目标列表使用独立可滚动的 radio group，避免 fieldset 内容绘制到窄屏底部按钮区域。
- **传统色主题**：新增雨过天青、艾绿春山、藕荷暮色、酪黄暖阳、丁香微雨、月白松烟。主题预览和页面共用深浅色值，支持中英文名称和持久化。色库来源、完整色值和浏览器实际颜色的对比度记录见 [08-传统色主题.md](./08-传统色主题.md)。
- **发布记录**：README 和商店素材说明加入 [Edge 正式链接](https://microsoftedge.microsoft.com/addons/detail/ncpniokijejakopmbfcjonalbdbggdah)，区分已发布的 1.0.0 和当前 1.1.0 更新候选版；package 与 manifest 版本统一为 1.1.0。

- `pnpm coverage`：**256 个用例通过，36 个测试文件**，全量及核心逻辑覆盖率门槛通过。语句 85.99%、行 89.92%、函数 83.11%、分支 75.52%。
